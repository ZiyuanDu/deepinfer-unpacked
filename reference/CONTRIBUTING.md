# 交流规范

本仓库围绕 DeepInfer 开展源码研读、文档整理和实验补充。DeepInfer 本身的 bug 请提交至 [上游仓库](https://github.com/deepseek-ai/DeepInfer/issues)。

## 基本规则

- 一个 issue 只讨论一个问题。
- 一个 PR 只处理一个 Topic。
- 请先检索文档和现有 issue。
- 请基于代码、文档和实验讨论问题。
- 请勿提交包含个人密钥、个人信息、私有代码或模型权重的内容。
- 请勿在本仓库提交属于 DeepInfer 上游仓库范围的 bug。
- 请勿公开报告安全漏洞。
- 请勿发表针对个人的攻击、骚扰或与项目无关的敏感内容。

详细规范见 [项目与流程](docs/reference/project/README.md)。
